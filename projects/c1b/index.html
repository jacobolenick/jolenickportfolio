Overview

Led the design and implementation of a comprehensive design system for a major credit card company, establishing design standards and component libraries that improved consistency across all digital products.

My role

Lead Product Designer

Challenge

The bank needed a Figma/Angular design system for the internal suite software that helps run the bank — with clear documentation and great collaboration, so the dev team could implement components, variables, and tokens quickly and other dev teams could build the screens.

User stories

  • We need to follow WCAG AA compliance rules and guidelines to ensure the product is accessible to all.
  • We need a dynamic customer panel — customer info, customer card + accounts, search + advanced search through filtering, recent history, and pricing strategy. One of the more complex components we’d build.

Better library performance

Strategically building components with well-structured properties keeps the design system file’s storage down, which keeps the file fast to work in — and saves the team’s budget by avoiding fees for storage limits.
